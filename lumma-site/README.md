# Lumma Landing Page V4.2

## Despliegue en Vercel

1. Sube esta carpeta completa a tu repositorio de GitHub
2. En Vercel, conecta el repositorio
3. Framework: Vite
4. Build command: `npm run build`
5. Output directory: `dist`

## Archivos importantes

- `src/App.jsx` — Landing page completa
- `public/images/team-lumma.jpg` — Foto del equipo
- `index.html` — Incluye favicon con isotipo de Lumma
